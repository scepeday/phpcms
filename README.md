
Project Description – EventHub CMS

EventHub CMS is a web-based content management system developed using PHP and MySQL to help event organizers efficiently manage all aspects of event planning in one platform. The system allows administrators to perform full CRUD (Create, Read, Update, Delete) operations across four main features.

The Events module enables users to create and manage event details such as name, date, and description. The Venues module allows management of event locations, including capacity and contact information. The Vendors module is used to store and update service providers like caterers, photographers, and decorators. Finally, the Bookings module manages guest registrations and RSVP details for each event.

This CMS provides a structured and user-friendly interface to organize event-related data, demonstrating full-stack development and database integration.
